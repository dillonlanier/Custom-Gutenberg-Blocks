== Description ==

This is a custom Gutenberg block created by Dillon Lanier using the Create Block tool and
leaning heavily on the Core Block components created by wonderful WordPress contributers.

The block is essentially an extended version of the 'Media and Text' block that comes in the
standard WordPress install, adding a header and buttons area along with some custom default
styling.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/image-text-block` directory.
2. Activate the plugin through the 'Plugins' screen in WordPress
